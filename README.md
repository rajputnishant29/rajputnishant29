### `> things_i've_shipped`

#### 🔐 Kryptit — Encryption SDK

<a href="https://www.npmjs.com/package/kryptit">
  <img src="https://img.shields.io/npm/v/kryptit?style=for-the-badge&logo=npm&logoColor=white" alt="Kryptit npm"/>
</a>

An open-source **TypeScript field-level encryption SDK** built around **AES-256-GCM**.

```text
AES-256-GCM
     │
     ├── Authenticated Encryption / Decryption
     ├── Nested Object Traversal
     ├── Array Support
     ├── CLI Key Generation
     └── Developer-first API
```

Built because I wanted to understand what happens beyond simply calling an encryption library.

→ **[Explore Kryptit](https://www.npmjs.com/package/kryptit)**
